## MemoMaster，轻量级的备忘录助手。

闲着没事干和 Gemini 一起写的备忘录管理器，可以：
 - 分行分科目录入作业。
 - 生成 png 作业图。
 - 在浏览器中预览。

整个玩意都是在浏览器里面跑的，总共只有一个单文件。  
秉持着轻量化 = 只写后端的原则，前端全部给浏览器自由发挥吧。  
我这次基本全部都交给 AI 来写了，没啥技术含量，也别来找我维护。  
当然你要是交 PR 我自然乐意哈。  

当然是没什么应用价值的，纯粹和 AI 闹着玩，当然你要是想用我也不拦着你 qwq

总之，欢迎使用！
